0. Strategy: module-first, E2E later (limited QA time)

Priority: Test individual modules first with stubbed or seeded data so we can validate each component without waiting for full pipelines or live E2E data. End-to-end testing is a later phase when time and environment allow.

  • Module-first: Each test target is a single module or integration point (e.g. MuleSoft API, ODS table, Tagetik loader, CMT view). We assert on that module's contract or state only.
  • Stub / seed to unblock: Use stubs (e.g. mock MuleSoft log responses, fixture DB state) or minimal seeded data so tests can run without full ADP/MuleSoft/D365 flows.
  • E2E later: Once module-level tests are in place and the pipeline is stable, add a small set of E2E scenarios. Optional in the first delivery window.

Implications: Design utilities and steps to accept real or stubbed inputs; prefer seeded DB/fixtures for DB tests; document what is stubbed per scenario.

4. Phased implementation (module-first, then E2E)

Phase 1 – Foundation: utilities, stubs, module-level steps

  • MuleSoft: correlation-ID search, message-type assertion, stub mode + fixtures.
  • Database: assertTableExists, queryRepositoryStatus, steps; at least one seed script.
  • Config: Lloyd's DB names and table names.
  • First Lloyd's feature file(s) under src/features/lloyds/ (modules only).

Phase 2 – Module-level test cases by epic

  • ENG-223: real auth + list apps.
  • ENG-1: DB-only for ENG-74, ENG-45, ENG-52, ENG-12 (ENG-2 when unblocked); seed if needed.
  • ENG-50, ENG-79: Tagetik loader existence/schema; optional seeded rows.
  • ENG-47 (module-level): stubbed logs + seeded DB; no E2E yet.
  • ENG-166, ENG-176: stubbed error logs.
  • PP-5, PP-278, PP-301: CMT/RDM DB checks; seeded data if available.

Phase 3 – E2E and Service Bus (when time and env allow)

  • PP-71, PP-390: queue/message constants; integration tests for feedback loop and 3-way reconciliation.
  • E2E: small set of full-flow scenarios (ADP → MuleSoft → D365/ODS); nightly or manual; not required for first delivery if time is short.
