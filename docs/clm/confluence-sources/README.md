## Data Migration from Microsoft Dataverse to Salesforce: ETL Process Overview and Key Principles

**Wiki:** https://accelins.atlassian.net/wiki/spaces/SA/pages/3155165214

Overview
This document outlines the approach for migrating data from Microsoft Dataverse to Salesforce using an Extract, Transform, Load (ETL) process. The objective is to ensure accurate, controlled, and auditable movement of data between systems while maintaining data integrity and supporting downstream business processes.
The migration is executed in three key stages:
Extract &ndash; Data is retrieved from Dataverse via the SQL endpoint and exported to structured CSV files. See:  Objectives
Ensure complete and accurate transfer of data from Dataverse to SalesforceMaintain referential integrity across all related objectsProvide a repeatable and auditable migration processEnable validation and reconciliation at each stage of the ETL processMinimise disruption to business operations during migrationKey Principles
Data integrity first &ndash; No transformation should alter the meaning of source dataTraceability &ndash; All records must be traceable from source to targetControlled transformations &ndash; All mapping and transformation logic must be documentedRe-runnability &ndash; Migration steps must be repeatable without duplication or data corruptionHigh-Level Architecture
