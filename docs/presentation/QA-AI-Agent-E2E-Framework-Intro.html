AI Agent

How We Use Cursor Agents

The agent lives inside the repo — same code, same commands, same review gates as the team

🤖 What the agent does

Generate Gherkin from Jira acceptance criteria

Write & fix step definitions using existing POM / steps

Run tests, read failures, patch the right layer

Scaffold new system clients, env config, and feature folders

🛡️ How we keep it safe

.cursorrules — reuse-first, no guessing business logic

.cursor/skills/ — team playbooks per system

QA review on every generated test case before Zephyr upload

Plain-English prompts that work today

  • "Generate UI and API tests for SF-736 and reuse existing party sync steps"
  • "Why did @api-ui fail on Reference Party — fix the SSIS wait timeout"
  • "Add Snowflake ADP read steps for MEMBER_WRITTEN_PREMIUM following lloyds-snowflake pattern"
Agent Guardrails

Three Layers That Steer the Agent

A

.cursorrules

Project rules — QA Architect role, reuse-first, layered architecture, no credential commits, ask before assuming

B

Project skills .cursor/skills/*/SKILL.md

Team workflows per system (Salesforce, Dynamics, SQL, MuleSoft) — versioned, shared via Git

C

npm automation commands

jira:generate test:feature zephyr:UploadResult validate:steps — agent and humans run the same pipeline

Docs: docs/process/CURSOR_PROJECT_SKILLS_SKILLMD_GUIDE.md · docs/QA_CURSOR_GETTING_STARTED.md

Extensibility

Adding a New App / System

Same layered pattern every time — the AI agent reuses it, so onboarding is days, not a greenfield rewrite

1

Environment & auth

Add credentials to .env.qa + config JSON — JWT, Entra SPN, or OAuth (patterns already exist)

2

Abstraction layer

API client (src/api-clients/) or Page Objects + Field Registry for UI

3

Reusable steps

Extend step-definitions/ — compose common steps; agent runs validate:steps → generate:steps

4

Features & tags

New folder under src/features/ · tag convention @PROJECT-KEY-UI-001

5

Agent skill (optional)

.cursor/skills/<system>-<task>/SKILL.md — teaches the agent your new system's rules
