Tool 1

📝 Test Case Generator

From Jira story to complete test cases in seconds

1

You have a Jira work item

Any QA-ready story — Salesforce (SF-520), Dynamics, ODS/TDS, or any project

2

Run one command

npm run jira:generate -- --work-item SF-520

3

Get complete test cases

Positive, negative, and edge case scenarios — all in Given/When/Then format

4

Review and improve

You add your domain expertise. The framework learns from your corrections.

⏰ 1-2 hours of manual work ➔ 30 seconds
Tool 2

📤 Zephyr Upload

Upload test cases AND results to Zephyr with one command each

📤

Upload Test Cases

npm run zephyr:UploadTestCase -- --work-item SF-520

Creates test cases in Zephyr Scale with all steps. Links to Jira story. Handles duplicates.

📈

Upload Results

npm run zephyr:UploadResult -- --work-item SF-520

Uploads pass/fail results with screenshots and evidence. No manual status updates.

⏰ 30+ min of clicking in Zephyr ➔ 1 command

Daily Workflow

Your New Daily Routine

Six simple steps. Mostly one command each.

1

Find what needs testing

npm run jira:find-missing — see all QA-ready stories

2

Generate test cases

npm run jira:generate -- --work-item SF-520 — creates feature files

3

Review and improve ⭐

This is where YOUR domain expertise matters — add, correct, refine the test cases

4

Upload to Zephyr

npm run zephyr:UploadAndLink -- --work-item SF-520 — test cases in Zephyr

5

Run tests (if scripts ready)

npm run test:feature -- --tags "@SF-520" — automated execution

6

Upload results

npm run zephyr:UploadResult -- --work-item SF-520 — done!
