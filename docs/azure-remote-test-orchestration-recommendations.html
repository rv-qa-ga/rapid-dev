Reference — triggers & glossary (compact)

TriggerFuture pattern
GearsetPipeline POST → Job API, high priority + deployment id
GitHubOIDC to Azure → POST Job API with sha / run id
JiraWebhook → Job API; idempotency_key
QAPortal or CLI → Job API, source=qa
NightlyAzure timer / Logic Apps → enqueue
TermShort meaning
EphemeralTemporary runner per job, then discarded
OrchestratorCoordinates dequeue, pool choice, limits (can live in workers at MVP)
QueueWaiting line + backpressure when many people trigger at once
