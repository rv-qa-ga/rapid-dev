h3. Framework expansion needed

The automation framework needs to be expanded with:

* *ODS* and *TDS* related test cases
* *Dynamics F&O* (Finance and Operations) test cases
* *Power BI report* test cases


h3. QA team scope

* The *yellow boxes* in the second diagram (e.g. Power BI Report, Tagetik, DCR) are *out of scope* for the QA team.
* *ADP* (Gen-2) is currently shown out of scope but *will become in scope* for end-to-end testing, as it is the *source of data* for the pipeline.


h3. Integrated lower environment

* We do *not* currently have a *lower environment integrated* for all systems.
* The gap is the *source system (ADP)* — ADP is missing in lower environments.
* We are working with the *ADP team* to come up with a solution. Once that solution is complete, we will be able to use it for *end-to-end testing*.
* There will be *work needed on the ODS side* to make this solution work in an *integrated environment*.

*More detail:* [Automation Testing Strategy for End-to-End Workflow|https://accelins.atlassian.net/wiki/spaces/TM/pages/1982333036/Automation+Testing+Strategy+for+End-to-End+Workflow] and [QA Automation Framework – Complete Workflow Guide|https://accelins.atlassian.net/wiki/spaces/TM/pages/2692710418/QA+Automation+Framework+-+Complete+Workflow+Guide].
